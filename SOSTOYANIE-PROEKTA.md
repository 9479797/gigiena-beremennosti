## План работ (16.11.2026)

Этапы идут по порядку; внутри этапа темы берутся по мере готовности. Что и когда отправлять врачу, решает автор (врач в процесс не встроен).

### Этап 1. Тексты: довести все части книги до проверенной редакции

1. **Проверка автором** — по папке «Мне проверить»: Тема 10 (в работе), затем Темы 5, 6, 7, 8, Тема 11 (редакция Claude 15.11), «Быстрая помощь» (кандидат с карточкой «Желтуха»), Введение (редлайн 16.11), содержание книги.
2. **Новая часть «Наблюдение беременности: учёт, визиты, обследования»** — единственная часть книги без собственного текста: есть только материал группы «Учёт и обследования по срокам» бывшего Приложения 1 (`themes/appendices/draft.md`). Написать по `kak-pisat-tekst.md` и сверстать по `verstka-tem.md`; сверить сроки и перечни с Приказом 747н и КР «Нормальная беременность» (проверить, нет ли новой редакции КР); вопросы 58–59 в `editorial/DISPUTED-CLAIMS.md`; добавить бланк «Мои лекарства и добавки».
3. **«Как проверять медицинскую информацию»** — текст есть (`themes/appendices/draft.md`, бывшее Приложение 2): сверстать как отдельную часть; прогнать запросы для ИИ в 3–4 чат-ботах по файлу «Проверка запросов ИИ 20.10.2026» (вопрос 63).
4. **Темы 3 и 4** — после проверки врачом 21.10 к новым правилам не приводились: срочность по трём уровням и «Быстрой помощи», вёрстка по образцу Темы 9.
5. **«Раздел 0» → «Быстрая помощь»** в текстах тем, Введения и самой «Быстрой помощи» — при правке каждого текста.

### Этап 2. Проверки каждой темы

6. **Юридическая проверка** (`yur-proverka-temy`) — пройдены Темы 1, 2, 9; остальные части — после проверки автором.

### Этап 3. Сборка книги

## Как восстановить работу в новом аккаунте

1. Создать в claude.ai проект «Гигиена беременности», подключить репозиторий
   `9479797/gigiena-beremennosti` (ветка `main`, папку `sources/` исключить).
2. Вставить в инструкцию проекта:

   ```
   # ПРОЕКТ: «ГИГИЕНА БЕРЕМЕННОСТИ»

   Рабочий язык — русский. Репозиторий `9479797/gigiena-beremennosti` — единственный
   постоянный SOURCE OF TRUTH проекта.

   Перед любой содержательной работой над темой сначала прочитать `AGENTS.md` в
   подключённом репозитории и определить по нему актуальные версии управляющих
   документов (project-instructions, editorial process spec, content map,
   canonical style corpus). Не восстанавливать канон, решения пользователя или
   медицинские факты по памяти чата — использовать актуальные файлы репозитория.

   Стандартные команды проекта (START THEME N, CONTINUE THEME N, STATUS THEME N,
   SAVE THEME N, SYNC PROJECT) и все приоритеты, роли skills и правила состояния
   тем определены в AGENTS.md и файлах editorial/.
   ```

3. В первом сообщении попросить прочитать `SOSTOYANIE-PROEKTA.md` и
   `claude/pamyat-claude-ai-2026-10-30.md` (удалён 15.11.2026, в истории Git, коммит 3bb9b2a) — второй файл заменяет потерянную
   память Claude.
4. Продолжать командами `STATUS THEME N` / `CONTINUE THEME N` / `REVIEW THEME N`.
