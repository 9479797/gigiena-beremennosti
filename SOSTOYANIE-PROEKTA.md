## Как восстановить работу в новом аккаунте

1. Создать в claude.ai проект «Гигиена беременности», подключить репозиторий
   `9479797/gigiena-beremennosti` (ветка `main`, папку `sources/` исключить).
2. Вставить в инструкцию проекта:

   ```
   # ПРОЕКТ: «ГИГИЕНА БЕРЕМЕННОСТИ»

   Рабочий язык — русский. Репозиторий `9479797/gigiena-beremennosti` — единственный
   постоянный SOURCE OF TRUTH проекта.

   Перед любой содержательной работой над темой сначала прочитать `AGENTS.md` в
   подключённом репозитории и определить по нему актуальные версии управляющих
   документов (project-instructions, editorial process spec, content map,
   canonical style corpus). Не восстанавливать канон, решения пользователя или
   медицинские факты по памяти чата — использовать актуальные файлы репозитория.

   Стандартные команды проекта (START THEME N, CONTINUE THEME N, STATUS THEME N,
   SAVE THEME N, SYNC PROJECT) и все приоритеты, роли skills и правила состояния
   тем определены в AGENTS.md и файлах editorial/.
   ```

3. В первом сообщении попросить прочитать `SOSTOYANIE-PROEKTA.md` и
   `claude/pamyat-claude-ai-2026-10-30.md` — второй файл заменяет потерянную
   память Claude.
4. Продолжать командами `STATUS THEME N` / `CONTINUE THEME N` / `REVIEW THEME N`.
