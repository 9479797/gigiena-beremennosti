# Источники и рекомендации

В этой папке хранятся клинические рекомендации, руководства, нормативные документы, научные источники и другие материалы, используемые при подготовке книги «Гигиена беременности».

По возможности для каждого источника следует сохранять название, организацию или автора, год публикации и ссылку на оригинал.

## Структура

- `russian-guidelines/` — действующие клинические рекомендации Минздрава России и официальные национальные рекомендации. **Первичный источник** порогов, критериев обращения к врачу, противопоказаний и сроков.
- `who-international/` — руководства ВОЗ и зарубежных обществ. Используются только при молчании российских рекомендаций и с проверкой применимости к РФ.
- `reviews/` — систематические обзоры и метаанализы (в т. ч. Cochrane). **Единственный** допустимый источник для цифр эффекта («снижает риск на N%»).
- `physiology/` — руководства по физиологии беременности. Источник механизмов и объяснений «почему так».
- `patient-materials/` — пациентские материалы ACOG, RCOG, NHS. Только карта читательских вопросов; утверждения в текст не переносятся.
- `periodicals/` — российская медицинская периодика (РМЖ, РМЖ. Медицинское обозрение). Только механизмы, комментарии к КР, русская терминология и контекст практики РФ. Пороги, дозы, сроки, цифры эффекта и названия препаратов брать нельзя; статьи не скачиваются, фиксируются в evidence ledger.

Правило использования каждого типа — в README соответствующей подпапки.

## Правило приоритета источников (кратко)

1. Пороги, дозы, сроки, критерии обращения к врачу — **только** `russian-guidelines/`; при их молчании — `who-international/` с явной отметкой о применимости к РФ.
2. Цифры вида «снижает риск на N%» — **только** `reviews/`, никогда из одного исследования.
3. Механизмы — из `physiology/` и `reviews/`.
4. Из `patient-materials/` утверждения в текст не переносятся.

## Уровень происхождения файла

Для каждого PDF фиксируется уровень происхождения: **1** — рубрикатор Минздрава
(rubricator.minzdrav.gov.ru), **2** — портал разработчика (для акушерства —
roag-portal.ru), **3** — сайт медучреждения, **4** — сторонняя перевёрстка.

Для работы используется файл **наименьшего доступного уровня**. Перевёрстки
уровня 4 источником не являются — только подтверждением совпадения редакции по
содержанию. Уровни имеющихся файлов проставлены в `README-inventory.md`.
