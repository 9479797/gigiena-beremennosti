# sources/reviews/

Систематические обзоры и метаанализы: Кокрейновские обзоры, метаанализы в
рецензируемых журналах, обзоры доказательств в составе руководств.

## Что сюда кладём

- Cochrane Database of Systematic Reviews.
- Систематические обзоры и метаанализы РКИ / когортных исследований.
- Разделы «evidence review» внутри крупных руководств, если используются
  отдельно.

Не кладём: отдельные первичные исследования (одно РКИ, одна когорта, серия
случаев), нарративные обзоры без систематического поиска, пресс-релизы.

## Что из этих документов МОЖНО брать в текст книги

Это **единственный** допустимый источник для **количественной оценки эффекта**:

- «снижает / повышает риск на N%», «в X раз», «на N случаев на 1000»;
- абсолютное и относительное снижение риска, NNT/NNH;
- направление и величина эффекта вмешательства (диета, активность, добавка,
  отказ от привычки).

Рядом с числом фиксируется: тип обзора, год, число включённых исследований и
участников, оценка определённости доказательств (GRADE: high/moderate/low/very
low), если приведена.

## Чего отсюда НЕ берём

- Пороги, дозы, сроки, критерии обращения к врачу — они из
  `russian-guidelines/` (при молчании — `who-international/`).
- Цифру эффекта из **одного** исследования, даже крупного, — не переносим.
  Нужен обзор или метаанализ.
- Если обзоры расходятся — не выбираем удобный, а помечаем расхождение для
  медицинской экспертизы (`UNRESOLVED`).

## Механизмы

Обзоры можно использовать и для объяснения механизмов — наравне с
`physiology/`.
