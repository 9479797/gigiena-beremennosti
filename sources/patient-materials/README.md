# sources/patient-materials/

Пациентские материалы зарубежных организаций: ACOG (FAQ), RCOG (patient
information), NHS (Pregnancy), а также пациентские приложения российских КР
(Приложение В).

## Зачем эта папка

Эти материалы показывают, **какие вопросы реально задаёт читатель** и в каком
порядке, какие формулировки ему понятны, какие темы люди ищут первыми. Это
карта читательских задач, а не источник медицинских утверждений.

## Что из этих документов МОЖНО брать

- **Только карту вопросов**: перечень и порядок вопросов читателя, границы
  темы глазами пациента, типичные заблуждения, которые стоит разобрать.
- Ориентиры по тону и уровню объяснения.

## Чего отсюда КАТЕГОРИЧЕСКИ НЕ берём

- **Утверждения в текст книги не переносятся.** Ни пороги, ни дозы, ни сроки,
  ни «безопасно / небезопасно», ни цифры эффекта, ни формулировки рекомендаций.
- Даже если памятка авторитетной организации что-то прямо утверждает — это
  утверждение должно быть заново подтверждено по `russian-guidelines/`,
  `who-international/` или `reviews/`, и в текст идёт уже оттуда.
- Пациентская памятка не является доказательством и не цитируется как
  обоснование медицинского тезиса.

## Правило приоритета источников

Действует общее правило из `sources/russian-guidelines/README.md`. Роль
`patient-materials/` в этой иерархии — нулевая для фактов и максимальная для
понимания читателя.
