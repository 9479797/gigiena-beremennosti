# sources/russian-guidelines/

Действующие клинические рекомендации Минздрава России и официальные
национальные рекомендации (РОАГ и профильные общества).

## Что сюда кладём

- Клинические рекомендации из рубрикатора Минздрава / с портала разработчика
  (roag-portal.ru) — только действующие редакции.
- Официальные методические письма и порядки оказания помощи Минздрава России,
  если они задают пороги, сроки или маршрутизацию.

Не кладём сюда: обзоры, отдельные исследования, зарубежные руководства,
пациентские памятки. Для них есть отдельные папки.

## Что из этих документов МОЖНО брать в текст книги

Это **первичный и приоритетный** источник для:

- **порогов** — числовые границы нормы и патологии (АД, прибавка массы тела,
  срок, кратность), при которых меняется тактика;
- **критериев обращения к врачу** — что и когда считается поводом связаться с
  врачом, приехать в приёмное отделение, вызвать скорую;
- **противопоказаний и ограничений** — когда нельзя, когда с осторожностью,
  когда только по назначению;
- **сроков** — недели беременности для скринингов, УЗИ, анализов, вакцинации,
  профилактики;
- **доз** — режимы приёма препаратов, витаминов и микроэлементов (Приложение А3
  рекомендаций).

## Правило приоритета источников (общее для всей папки sources/)

1. Пороги, дозы, сроки и критерии обращения к врачу берутся **ТОЛЬКО** из
   russian-guidelines. При их молчании — из международных руководств
   (`who-international/`) с явной отметкой о проверке применимости к РФ.
2. Цифры вида «снижает риск на N%», «эффект в X раз» — **только** из
   систематических обзоров и метаанализов (`reviews/`), **никогда** из одного
   исследования.
3. Механизмы и объяснения «почему так» — из `physiology/` и `reviews/`.
4. Из `patient-materials/` утверждения в текст **не переносятся** — только карта
   вопросов и структура читательских задач.

## Как ссылаться

Указывать: название рекомендации, ID рубрикатора, год утверждения и год
пересмотра, номер раздела/приложения, уровень убедительности рекомендации
(A/B/C) и достоверности доказательств (1–5), если он приведён у конкретного
тезиса.

Полный перечень скачанных документов с оглавлениями — в
`sources/README-inventory.md`.
