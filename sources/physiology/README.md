# sources/physiology/

Руководства и учебные источники по физиологии беременности: что и почему
меняется в организме — сердечно-сосудистая система, гемостаз, ЖКТ, кожа, сон,
дыхание, мочевыделение, эндокринология беременности.

## Что сюда кладём

- Главы и руководства по нормальной физиологии беременности (акушерство,
  разделы «physiological changes in pregnancy»).
- Обзорные физиологические статьи о конкретных системах при беременности.

## Что из этих документов МОЖНО брать в текст книги

Только **механизмы и объяснения «почему так»**:

- почему меняется сон, пищеварение, кожа, отёчность, переносимость нагрузки;
- почему растёт риск тромбозов, изжоги, запоров, заложенности носа;
- как физиологический сдвиг объясняет жалобу, которая при этом остаётся
  нормой.

Это отвечает на вопрос **WHY** во фрейме
WHAT → WHY → RECOGNITION → ACTION → NEXT STEP → SAFETY.

## Чего отсюда НЕ берём

- Пороги, дозы, сроки, критерии обращения к врачу — из `russian-guidelines/`.
- Цифры эффекта вмешательств — из `reviews/`.
- «Раз это физиологично — значит, всегда безопасно» — такой вывод не делаем;
  границу нормы задаёт клиническая рекомендация, а не физиологический механизм.

## Правило приоритета источников

Действует общее правило из `sources/russian-guidelines/README.md`. Механизм из
`physiology/` не отменяет порог из `russian-guidelines/` и не заменяет оценку
эффекта из `reviews/`.
