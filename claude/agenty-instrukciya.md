# Агенты проекта — краткая инструкция

В проекте два агента. Каждый работает отдельно от нашего разговора, на модели
Sonnet, а результат приходит сюда. Текст глав они не правят, медицинских решений
не принимают и ничего не удаляют. Правки текста делаем мы с вами в основной сессии.

Чтобы вызвать агента, назовите его в сообщении. Точная формулировка не важна,
примеры ниже.

## Сверщик — порядок в книге и в репозитории

| Что сказать | Что будет |
|---|---|
| «сверщик, SAVE THEME 7» | Тема сохраняется в GitHub: файл темы, README, реестр, коммит |
| «сверщик, SYNC PROJECT» | Проверка репозитория: версии, ссылки, дубли; ничего не удаляет |
| «сверщик, обнови карту книги» | `editorial/book-map.md`: заголовки, пороги, отсылки всех тем |
| «сверщик, сверка тем» | Отчёт о расхождениях между темами в `editorial/reports/sverka-….md` |

Сверку всех тем запускаем, когда будут написаны оставшиеся темы.

## Источниковед — источники, долгая работа в фоне

| Что сказать | Что будет |
|---|---|
| «источниковед, разведка темы 9» | Из чего может состоять тема, какие документы есть и каких не хватает |
| «источниковед, реестр источников темы 9» | Дословные цитаты из источников в реестр темы |
| «источниковед, открытые вопросы темы 6» | Поиск источников под `[ПРОВЕРИТЬ]` и SOURCE NEEDED |
| «источниковед, список источников темы 8 по стандарту» | Готовый список по образцу Темы 5 в отдельном файле |
| «источниковед, проверь ссылки» | Какие ссылки в списках источников не открываются или ведут не туда |
| «источниковед, внеси скачанные файлы в инвентарь» | Новые файлы из `sources/` проверяются и вносятся в опись |

Он работает в фоне: пока он ищет, мы продолжаем работу над текстом, а по
окончании приходит сообщение. Результат сохраняется в GitHub порциями, поэтому
прерванную работу можно продолжить с того же места. Долгое задание можно
поставить на ночь — попросите меня запустить его по расписанию. Остановить —
«останови источниковеда».

## Что делаете вы: ссылки на проверку и ручная загрузка

Некоторые сайты закрыты для машинной проверки (сайт Минздрава с клиническими
рекомендациями, ACOG, JAMA, Wiley). Если источниковед не может открыть ссылку,
он не ждёт: заканчивает задание без неё, а ссылку вносит в
`sources/skachat-vruchnuyu.md`. Выводы, которые держатся только на такой
ссылке, он помечает в отчёте как предварительные. В каждой записи — ссылка,
запасной путь, что проверить при открытии и, если файл нужен, куда его
положить.

1. Откройте ссылку и проверьте то, что написано в записи. Если всё верно —
   «запись 4 проверена».
2. Если файл нужно скачать — положите его в указанную папку на GitHub:
   «Add file» → «Upload files» → «Commit changes». Или прикрепите его в чат:
   «положи в sources». Затем: «источниковед, внеси скачанные файлы в
   инвентарь».
3. Если ссылка не открылась или ведёт не туда — «запись 4 не работает». Агент
   найдёт другую.

## Где смотреть, как идёт работа

Отдельного чата агент не создаёт: он работает внутри того разговора, где его
запустили, и сюда приходит итог, а не каждый шаг. Следить за ходом можно так:

- спросить здесь: «как дела у источниковеда?»;
- на GitHub: после каждой порции агент сохраняет результат — в истории
  репозитория появляются коммиты «Источники: …, порция K», а в его отчёте в
  `editorial/reports/` раздел «Ход работы» показывает, что сделано, что
  осталось и на чём он остановился;
- ночной запуск по расписанию идёт отдельной сессией, её можно открыть и
  читать как обычный чат.

Агенты работают только в сессиях с подключённым репозиторием, как эта. В
обычном чате проекта на claude.ai их нет.

## Где что лежит

| Что | Где |
|---|---|
| Отчёты агентов | `editorial/reports/` |
| Список для ручной загрузки | `sources/skachat-vruchnuyu.md` |
| Новые списки источников тем | `themes/theme-N/spisok-istochnikov-v2.md` |
| Файл темы | `themes/theme-N/theme N draft.docx` |
| Правила агентов | `.claude/agents/sverschik.md`, `.claude/agents/istochnikoved.md` |

После каждого сохранения в GitHub нажмите Sync в панели Context на claude.ai,
чтобы проект увидел новые файлы.
