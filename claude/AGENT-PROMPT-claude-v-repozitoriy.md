# Промт для терминального агента: перенос папки `claude/` в репозиторий

Репозиторий `9479797/gigiena-beremennosti`, ветка `main`.

Пользователь скачал из чата архив `claude-i-tema-8.zip` и положил его в корень
репозитория. В архиве:

- `claude/` — рабочие файлы проекта (трекер отложенных задач, находки,
  промты `AGENT-PROMPT-*`), до сих пор хранившиеся только в базе знаний
  claude.ai;
- `themes/theme-8/draft.md` — черновик Темы 8 (редакция 2).

## Шаги

1. Распаковать архив в корень репозитория (`unzip claude-i-tema-8.zip`).
   Если какой-то файл уже существует — не перезаписывать молча, показать
   разницу и спросить. Архив после распаковки удалить, в репозиторий его не
   добавлять.
2. В `AGENTS.md`, раздел «Что прочитать перед работой» или близкий по смыслу,
   добавить короткий пункт: «`claude/` — рабочие заметки и промты для
   терминального агента из чата claude.ai: трекер открытых задач
   `claude/otlozhennye-zadachi.md`, находки по источникам, промты
   `AGENT-PROMPT-*`. Промты выполняются только по указанию пользователя».
3. Выполнить промт `claude/AGENT-PROMPT-theme8-start.md` (Тема 8 и снятие
   ограничений в правилах).
4. Уже выполненные промты (`AGENT-PROMPT-theme3-doctor-review.md`,
   `AGENT-PROMPT-grls-theme5-theme6-closeout.md`) повторно не выполнять:
   их правки уже в `main` (коммит `58453d8` и последующий). Перед тем как
   это утверждать в отчёте, проверить grep'ом: в
   `themes/theme-1/evidence-ledger.md` есть строки про «Адиарин
   Регидрокомплекс» и «Хумана Электролит»; в `editorial/DISPUTED-CLAIMS.md`
   строка 14 содержит «источники получены».
5. Один коммит: «claude/: рабочие заметки и промты перенесены в репозиторий;
   Тема 8 — черновик». Пуш — по решению пользователя.
