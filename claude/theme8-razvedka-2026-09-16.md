# Разведка Темы 8 — «Привычки, воздействия и повседневная безопасность»

Проведена 2026-09-16 по `editorial/theme-reconnaissance-v1.0.md`. Тема — пилотная
для действующих `text-architecture-v1.2` и `tone-of-voice-v1.1` (AGENTS.md).
`themes/theme-8/` в репозитории отсутствует — тема действительно не начата,
папку и README не создавал: разведка предшествует инициализации.

Coverage и границы — `editorial/pregnancy-book-evidence-content-map-v3.0.md`.
Тема разделена Content Map на две части, потолок узлов (18) применяется к
каждой отдельно:

- **Часть A** — «Алкоголь, никотин и другие вещества» (8 пунктов coverage,
  заданный тон: evidence → practical risk → risk reduction → help pathway,
  без морализаторства);
- **Часть B** — «Дом, работа и окружающая среда» (20 пунктов coverage).

Legacy-исходника у темы нет (`themes/SOURCE-TEXT-MAPPING.md`): собирать нужно
через `research/evidence`, а не через готовый черновик — `research/theme-8/`
в репозитории тоже пока не существует.

## 3. Пересечения (theme-reconnaissance §3.7)

1. **B9 (профессиональные химические воздействия) ↔ Тема 5.** Тема 5 уже
   содержит проверенное утверждение (`VERIFIED`, источник MotherToBaby) про
   формальдегид при химическом/кератиновом выпрямлении волос и повышенный
   риск выкидыша у людей, постоянно работающих с формальдегидом. Это ровно
   предметная область B9/B2. Решение по разводке — за пользователем на
   Checkpoint 0: (а) Тема 8 даёт общий принцип профессиональных химических
   воздействий с cross-link на конкретный пример в Теме 5, не повторяя его;
   (б) либо пример остаётся только в Теме 5, а Тема 8 ограничивается другими
   веществами. Дублирование без решения — риск ровно того типа, что описан в
   `editorial/evidence-discovery-v1.0.md` §1.4 (бензоила пероксид/буквенные
   категории FDA между Темами 5 и 7).
2. **B5 (сауна/баня) ↔ Тема 5.** Тема 5, раздел 5.5, уже поднимает сауну/баню
   (реестр, строка 21) и оставлена на решение врача-рецензента. Если Тема 8
   тоже берёт этот узел — нужно either дождаться решения врача и
   синхронизировать формулировку, either явно развести: Тема 5 — про кожу и
   перегрев тела в бытовом контексте личной гигиены, Тема 8 — про тепловое
   воздействие как фактор повседневной безопасности в целом. Решение —
   пользователю.
3. **B7 (сидение/эргономика) ↔ Тема 3.** Тема 3 (раздел 3.8) уже разбирает
   боль в спине и тазу; Content Map прямо связывает Тему 3 и Тему 8
   cross-link’ом. Не проверено детально, что именно уже сказано в 3.8 —
   кандидат на сверку при написании черновика, не блокирует разведку.
4. **B12 (ионизирующее излучение) ↔ Тема 6.** Тема 6, раздел 6.7, уже ведёт
   открытый вопрос по СанПиН (DISPUTED-CLAIMS строка 13) для стоматологического
   рентгена конкретно. Тема 8 должна взять тот же нормативный акт для общего
   случая (профессиональное облучение, другая визуализация) и **не
   инициировать вторую независимую проверку статуса документа** — статус уже
   установлен, использовать его.
5. **B16–B18 (перелёты/длительные поездки/путешествия) — внутренняя
   избыточность.** Судя по содержанию источника (КР «Венозные осложнения»),
   это, вероятно, один механизм (иммобилизация → риск ВТЭО) с разными
   бытовыми поводами, а не три разных узла — кандидат на объединение на
   Checkpoint 0, а не на разведке (разведка не решает архитектуру).
6. **A9 (кофеин) — не кандидат, а предупреждение против дублирования.**
   Кофеин уже подробно разобран в Теме 2 (узел 6). Часть A по своему coverage
   его не называет — упомянуто на случай, если при работе с источниками
   всплывёт соблазн взять его туда же.

## 4. Дефицит источников (theme-reconnaissance §4.2)

Прежде чем писать черновик, блокирующим для соответствующих узлов является
отсутствие:

1. **Профильной КР/норматива по употреблению алкоголя, табака и
   психоактивных веществ при беременности** (Часть A целиком, кроме общего
   упоминания в §5.1 «Нормальной беременности»). Без него узлы A1, A3–A8 не
   имеют российской границы нормы; международные источники (ACOG/RCOG/WHO)
   можно взять только при подтверждённом молчании российского документа — а
   его для начала нужно поискать и либо найти, либо честно зафиксировать
   отсутствие.
2. **Российского норматива условий труда для беременных** (тяжесть труда,
   ночные смены, химические/биологические/физические профвредности,
   перевод на лёгкий труд) — ожидаемо ТК РФ ст. 254 плюс профильный
   санитарный норматив. Блокирует B6, B8–B11, B13–B14 целиком. Это
   самостоятельная и довольно объёмная предметная область — вероятно,
   стоит скачивать отдельным заходом, а не точечно.
3. **Полного текста СанПиН 2.6.4115-25** — статус документа уже установлен
   (не заявка на поиск, а заявка на скачивание/чтение полного текста), нужен
   для B12 и параллельно для незакрытого вопроса Темы 6.
4. Точечно: правило о ремне безопасности при беременности (B15) — вероятно,
   есть в памятке ГИБДД или в самой «Нормальной беременности», не проверялось
   целенаправленно.

## 5. Незакрытые обязательства (theme-reconnaissance §4.4)

Content Map указывает cross-links Темы 8 с Темами 3, 5, 9, 11/Раздел 0.
Явных текстовых обещаний вида «подробнее в Теме 8» в уже написанных главах
(1–7) при проверке не нашлось — то есть входящих обязательств, которые Тема 8
обязана закрыть, на сегодня не зафиксировано. Есть, однако, обратное:
**Тема 8 сама будет должна нескольким темам** cross-links на уже написанное —
кофеин (Тема 2), боль в спине/эргономика (Тема 3), формальдегид и сауна/баня
(Тема 5), ионизирующее излучение при стоматологии (Тема 6) — это отражено в
разделе «Пересечения» выше и должно войти в Cross-links README Темы 8 при
инициализации.

Темы 9 и 11/Раздел 0, с которыми у Темы 8 тоже заявлен cross-link, ещё не
написаны — входящих обязательств от них нет, но при их будущей разработке
стоит свериться с Темой 8 (падения/травмы → Раздел 0; путешествия/инфекции →
Тема 9).
