# Diagrams

В этой папке хранятся визуальные схемы проекта «Гигиена беременности».

Диаграммы служат для навигации и быстрого понимания структуры проекта и workflow.

Они не являются нормативным источником процесса.

При расхождении с визуальной схемой приоритет имеют:
- `AGENTS.md`;
- `editorial/project-instructions-v1.7.md`;
- `editorial/pregnancy-book-editorial-v1.6.md`;
- `editorial/pregnancy-book-evidence-content-map-v3.0.md`;
- утверждённые решения пользователя.

Текущая PNG-карта может содержать подписи версий, актуальные на момент её создания. При изменении версий управляющих документов ориентироваться на список выше; визуальную карту обновлять после стабилизации соответствующего изменения процесса.
