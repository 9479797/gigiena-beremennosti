# HTML-версия книги: защита от копирования

Решения пользователя о защите онлайн-версии книги от копирования текста и просмотра кода (F12). Применять при вёрстке в HTML и загрузке книги на платформу. Технические детали (коды, проверка на тестовом уроке) прорабатываются при загрузке книги.

## 20.10.2026 — исходные условия

1. **Полностью закрыть текст нельзя.** Всё, что браузер показал читательнице, у неё уже есть: F12, «Сохранить страницу», отключённый JavaScript, скриншоты с распознаванием текста. Меры в коде отсекают неподготовленного читателя, остальное держится на доступе по логину, водяных знаках и юридической защите.
2. **Вес страницы.** Меры защиты не должны заметно увеличивать размер файлов и время загрузки. Меры, которые почти не влияют на загрузку, брать в работу.
3. **Mobile first.** Книга верстается в первую очередь под телефон.
4. **Размещение.** Книга — урок (уроки) GetCourse с доступом по логину GetCourse; должна отображаться и в мобильном приложении GetCourse. Сеансы на аккаунт ограничиваются в настройках GetCourse, в коде книги не делаются.

## Меры, принятые в работу

| Мера | Где работает | Добавляет к странице |
|---|---|---|
| Помехи в коде: запрет контекстного меню, копирования, горячих клавиш (F12, Ctrl+Shift+I/J/C, Ctrl+U/S/P), скрытие книги при печати | код урока | до 1 КБ |
| Скрытый встроенный текст (см. ниже) | код урока | 2–4 КБ на главу |
| Подмена части кириллицы на похожую латиницу при копировании | код урока | до 1 КБ вместе со следующей мерой |
| Подпись-источник к скопированному фрагменту («Источник: „Гигиена беременности“, ссылка») | код урока | — |
| Шрифтовая обфускация только для ценных фрагментов (таблицы, протоколы) | код урока + файл шрифта | 10–20 КБ, шрифт кешируется |
| Персональный водяной знак читательницы (ID в тексте) | код урока | входит в скрытый текст |
| Ловушки для программ-парсеров (скрытый элемент, который обычный браузер не загружает) | код урока | десятки байт |
| Вход по логину, выдача по урокам, ограничение сеансов | GetCourse | 0 |
| Мониторинг копий (проверка уникальности, поиск по уникальным фразам книги) | вне сайта | 0 |
| Юридическая защита: ©, условия использования, фиксация авторства, жалобы хостингам и поисковикам на пиратские копии | вне сайта | 0 |

### Скрытый текст — способ реализации

- Прятать через CSS (`position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); white-space: nowrap;`), **не цветом фона**: цвет фона проявляется при выделении и в тёмной теме, его зачитывают программы экранного доступа, поисковики считают его манипуляцией.
- `aria-hidden="true"` на каждой вставке.
- Названия классов случайные и разные, не один общий класс на все вставки.
- Вставки в середину предложений, а не между абзацами.
- В скрытый текст подставляется ID читательницы — он же водяной знак.
- Вставки расставляются автоматически скриптом при сборке HTML, а не вручную в текстах тем.

### Шрифтовая обфускация — условия

- В исходном коде символы заменены по правилу подстановки, веб-шрифт рисует на их месте правильные буквы.
- Только для отдельных фрагментов: отключает поиск по странице, переводчик браузера и программы экранного доступа; открытые для поиска страницы (оглавление, фрагменты) не обфусцировать.
- Шрифт содержит только буквы этих фрагментов (subset).
- `font-display: block`, а не `swap`: иначе на медленном мобильном интернете на мгновение видны перепутанные буквы.
- Отдельная перестановка на главу или читательницу усложняет восстановление текста по таблице шрифта.

## Не брать

- **Ограничение скорости выдачи страниц** на сервере (решение пользователя).
- **Отрисовка фрагментов в canvas или картинками** — большой вес картинок; заменена шрифтовой обфускацией тех же фрагментов.
- **Перестановка фрагментов текста в коде с пересборкой через CSS** — разметка растёт в 2–3 раза, на узких экранах вёрстка ломается.
- **Отдельное шифрование текста главы** — доступ и выдача по урокам уже даёт GetCourse.
- **Скрипты «обнаружения DevTools»** (бесконечный `debugger`, замер окна) — ненадёжны, ломают сайт у обычных читательниц.
- **Ссылки на главы с коротким сроком действия, запрет встраивания через заголовки сервера** — при размещении в GetCourse доступ закрыт логином, заголовки сервера платформы менять нельзя.

## Проверить на тестовом уроке до вёрстки книги

1. Выполняет ли мобильное приложение GetCourse скрипты из HTML-блока урока. Если нет — в приложении не сработают помехи, подпись и подмена букв при копировании; скрытый текст и шрифтовая обфускация работают на CSS.
2. Подгружает ли приложение свой шрифт (файл — в хранилище GetCourse или на CDN). Без этого обфусцированные фрагменты нечитаемы.
3. Можно ли подставить ID ученика в HTML-блок урока переменными платформы. Если нет — водяной знак вставляется скриптом и в приложении без скриптов пропадает.
4. Блокировка аккаунта по срабатыванию ловушки в GetCourse автоматически невозможна — решить, записывать ли срабатывания для ручной блокировки.
