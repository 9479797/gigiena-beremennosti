# HTML-версия книги: навигация

Решения пользователя для онлайн-версии книги: навигация и интерактивные элементы. Применять при вёрстке в HTML.

## 18.10.2026 — навигаторы и обратные ссылки

1. **Навигаторы (Приложение 1 — обе части, таблица Раздела 0).** В HTML вместо таблицы — список строк «Что вы заметили» (или «Что случилось или предстоит»). Под каждой строкой — ссылки, которые открывают нужные материалы: раздел темы и, если нужно, пункт Раздела 0. Текст и оформление ссылок продумать отдельно (варианты: «Открыть: Тема 11, раздел 11.2», «Читать подробнее», кнопка с названием раздела; ссылка на Раздел 0 выделяется как срочная).
2. **Обратная ссылка из материала.** В разделе, куда перешла читательница, есть ссылка «назад», и она возвращает **ровно в то место, где была нажата ссылка «открыть»**: к той же строке навигатора, а не в начало приложения.
3. **Навигация по пути читательницы.** Возврат определяется тем, откуда она пришла (из Приложения 1, Раздела 0, Введения или другой темы), а не фиксированной ссылкой. Если пришла не по ссылке (напрямую, из поиска), ссылка «назад» не показывается или ведёт к оглавлению — решить при разработке.
4. Те же правила — для всех перекрёстных ссылок вида «Подробнее: Тема N, раздел N.N».

## Что подготовить в текстах

- У каждого раздела и пункта Раздела 0 — постоянный якорь (например, `#t11-2`, `#r0-9`), чтобы ссылки не ломались при правках текста.
- У каждой строки навигаторов — свой якорь (например, `#p1-sheveleniya`), чтобы было куда возвращаться.

## 20.10.2026 — Приложение 1: кнопки вместо ссылок на темы (решение пользователя)

Требование пользователя: вместо указаний «Тема N, раздел N.N» — кнопки; отдельная кнопка открывает текст в Разделе 0; интерфейс должен быть понятен любому человеку сразу при открытии.

**Как устроить экран:**

1. **Одна строка пояснения вверху**, не больше: «Найдите, что вас беспокоит. Красная кнопка — что делать срочно. Жёлтая строка — когда позвонить врачу раньше приёма. Серая кнопка — прочитать подробнее». Строки разбиты на группы по частям тела (живот и выделения; голова, давление, отёки; дыхание и температура; мочеиспускание и пищеварение; кожа; спина и ноги; сознание; сон и настроение; зубы; ребёнок; анализы) — в HTML это фильтры-кнопки над списком.
2. **Поиск** — поле «Начните вводить: кровь, давление, сыпь…», строки отфильтровываются по мере ввода (по названию строки и по синонимам).
3. **Две вкладки**: «Что я заметила» и «Что случилось». Внутри — список по алфавиту.
4. **Каждая строка — карточка**, а не строка таблицы:
   - крупно — что заметили («Шевеления реже, слабее или не такие, как обычно»);
   - если в столбце Раздела 0 «всегда» — карточка с красной полосой и красной кнопкой **«Что делать сейчас»** (открывает пункт Раздела 0);
   - если срочность зависит от условия — под названием строка «Срочно, если: отекают губы, язык, горло, трудно дышать» и рядом красная кнопка **«Что делать»**;
   - жёлтая строка без кнопки **«Позвонить врачу раньше приёма: …»** — условие из одноимённого столбца (добавлен 20.10.2026), если он не пуст;
   - серая кнопка **«Подробнее»** с понятной подписью темы словами, без номеров: «Подробнее: аллергия», «Подробнее: сон»; если разделов два-три — две-три серые кнопки.
5. **Номера тем и разделов на кнопках не показывать** — они остаются в адресе ссылки и в печатной версии.
6. **Телефон:** кнопки во всю ширину, высота не меньше 44 px; красный цвет — только для срочного, чтобы его нельзя было спутать с остальным.
7. **Возврат** — по правилам выше: кнопка «Назад к навигатору» возвращает к той же карточке.

**Что подготовить в тексте:** для каждой ссылки «Где читать» — короткая подпись кнопки словами (2–3 слова). Сделать при вёрстке HTML; в `draft.md` (основа печатной версии) остаются номера тем и разделов.

## 20.10.2026 — макет объединённого Раздела 0 (утверждён пользователем 20.10.2026)

Макет: артефакт «Навигатор по признакам — макет» (Design-холст в claude.ai). Решение пользователя 20.10.2026: Раздел 0 и Приложение 1 объединяются в один вход «Что вы заметили». Состав плиток и карточек — `themes/theme-0/plitki-navigatora.xlsx`.

Что уже решено по интерфейсу (замечания пользователя 20.10.2026):

- 15 плиток одного уровня: 9 групп признаков и 6 групп «Что-то случилось» (подзаголовок, а не второй уровень); группа «Предстоит» снята. На плитках — только название, без цветных точек.
- Список карточек скрыт; нажатие на плитку открывает только эту группу. Переход виден: плитки уходят, группа въезжает справа, в шапке — путь «Раздел 0 › Что вы заметили» и крупный заголовок группы; кнопка «Все группы» — над списком строк, под шапкой (там до неё легко дотянуться — замечание пользователя); страница прокручивается в начало. Возврат — въезд плиток слева. Без анимации при `prefers-reduced-motion`.
- Строка группы раскрывается: справа круглая кнопка со стрелкой вниз, при открытии стрелка поворачивается; над списком подсказка «N строк. Нажмите на строку, чтобы открыть».
- Единый знак раскрытия: всё, что раскрывается (строка группы и вложенный блок «Что сказать диспетчеру и что взять с собой»), имеет одинаковую круглую кнопку со стрелкой вниз справа; при раскрытии стрелка поворачивается. Переход в книгу («Подробнее в книге: …») — стрелка вправо, чтобы не путать с раскрытием (замечание пользователя 20.10.2026: вложенные блоки иначе не заметят).
- Цветная точка у строки — срочность: красная — всегда срочно, жёлтая — зависит от условий, серая — обычно не срочно.
- Скорая без повторов (замечание пользователя 20.10.2026): на экране плиток вверху одна низкая строка «Резко стало плохо — звоните» с кнопками 103 и 112, внизу — «Не нашли своё… позвоните своему врачу сегодня». Внутри группы верхней строки нет: у срочных строк своя кнопка «Позвонить 103», а внизу один блок «Если вам резко стало хуже, вызывайте скорую. Выяснять причину не нужно — это сделают врачи» с кнопками 103 и 112.
- Тексты: заголовок «Что вас беспокоит?», подпись «Раздел 0. Быстрая помощь», путь «Быстрая помощь › Что вас беспокоит», подсказка «Выберите группу симптомов» (текст пользователя). В карточке — повелительные заголовки блоков: «Вызывайте скорую, если», «Поезжайте в роддом сразу, если», «Чего не делать», «Позвоните своему врачу…, если», «Что важно знать», «Читать подробнее: …». Пояснение к цветным точкам — над списком группы: «нужна срочная помощь / срочная помощь нужна в некоторых случаях / срочная помощь обычно не нужна». Внутри группы строки упорядочены по срочности: сначала красные, затем жёлтые, затем серые (решение пользователя 20.10.2026); в печатной версии — так же.

**Адаптивность (требование пользователя: все устройства, включая ПК).** Макет нарисован для телефона (390 px). В коде книги: телефон — как в макете; планшет — плитки в 3 колонки; ПК (от ~1024 px) — две панели: слева плитки (список групп, выбранная подсвечена), справа карточки выбранной группы, без анимации ухода плиток; ширина текста карточки не больше ~70 знаков; всё управляется с клавиатуры (Tab, Enter, Esc — назад к группам).
