# HTML-версия книги: навигация

Решения пользователя для онлайн-версии книги: навигация и интерактивные элементы. Применять при вёрстке в HTML.

## 18.10.2026 — навигаторы и обратные ссылки

1. **Навигаторы (Приложение 1 — обе части, таблица Раздела 0).** В HTML вместо таблицы — список строк «Что вы заметили» (или «Что случилось или предстоит»). Под каждой строкой — ссылки, которые открывают нужные материалы: раздел темы и, если нужно, пункт Раздела 0. Текст и оформление ссылок продумать отдельно (варианты: «Открыть: Тема 11, раздел 11.2», «Читать подробнее», кнопка с названием раздела; ссылка на Раздел 0 выделяется как срочная).
2. **Обратная ссылка из материала.** В разделе, куда перешла читательница, есть ссылка «назад», и она возвращает **ровно в то место, где была нажата ссылка «открыть»**: к той же строке навигатора, а не в начало приложения.
3. **Навигация по пути читательницы.** Возврат определяется тем, откуда она пришла (из Приложения 1, Раздела 0, Введения или другой темы), а не фиксированной ссылкой. Если пришла не по ссылке (напрямую, из поиска), ссылка «назад» не показывается или ведёт к оглавлению — решить при разработке.
4. Те же правила — для всех перекрёстных ссылок вида «Подробнее: Тема N, раздел N.N».

## Что подготовить в текстах

- У каждого раздела и пункта Раздела 0 — постоянный якорь (например, `#t11-2`, `#r0-9`), чтобы ссылки не ломались при правках текста.
- У каждой строки навигаторов — свой якорь (например, `#p1-sheveleniya`), чтобы было куда возвращаться.

## 20.10.2026 — интерактивные элементы приложений (пункты 1–2 — решения пользователя)

1. **Приложение 2 «Мои лекарства и добавки» — скачать пустую таблицу.** Рядом с таблицей кнопка «Скачать таблицу для печати»: файл с пустой таблицей теми же столбцами (PDF для печати; по возможности ещё редактируемый файл — решить при разработке). Таблица в HTML остаётся видимой как образец.
2. **Приложения 4 и 5 — запросы для ИИ с кнопкой «Скопировать».** Каждый запрос — один абзац, требования к ответу встроены в него (решение пользователя 20.10.2026: «чтобы беременная могла просто скопировать промт из одного абзаца»). В HTML у запроса — поля вместо пропусков: срок (недели), главное поле (название лекарства, продукта, симптома, текст для проверки), в запросе о лекарстве — необязательное поле «что ещё принимаю». Кнопка «Скопировать» кладёт в буфер обмена абзац с вписанными значениями; пустое главное поле — подсказка «впишите название». Введённое никуда не отправляется и не сохраняется: всё делается в браузере. Под кнопкой — «Вставьте в окно чат-бота». Тексты запросов — в `themes/appendices/draft.md`, разбор вопросов — `themes/appendices/voprosy-v-internete-i-prompty.md`.
3. *Предложение, пользователем не утверждено.* **Приложение 5 — чек-лист с отметками.** Пункты чек-листа — флажки, которые можно отметить на экране; ссылки на российские ресурсы проверки лекарств открываются в новой вкладке.

## 20.10.2026 — Приложение 1: кнопки вместо ссылок на темы (решение пользователя)

Требование пользователя: вместо указаний «Тема N, раздел N.N» — кнопки; отдельная кнопка открывает текст в Разделе 0; интерфейс должен быть понятен любому человеку сразу при открытии.

**Как устроить экран:**

1. **Одна строка пояснения вверху**, не больше: «Найдите, что вас беспокоит. Красная кнопка — что делать срочно. Серая — прочитать подробнее».
2. **Поиск** — поле «Начните вводить: кровь, давление, сыпь…», строки отфильтровываются по мере ввода (по названию строки и по синонимам).
3. **Две вкладки**: «Что я заметила» и «Что случилось». Внутри — список по алфавиту.
4. **Каждая строка — карточка**, а не строка таблицы:
   - крупно — что заметили («Шевеления реже, слабее или не такие, как обычно»);
   - если в столбце Раздела 0 «всегда» — карточка с красной полосой и красной кнопкой **«Что делать сейчас»** (открывает пункт Раздела 0);
   - если срочность зависит от условия — под названием строка «Срочно, если: отекают губы, язык, горло, трудно дышать» и рядом красная кнопка **«Что делать»**;
   - серая кнопка **«Подробнее»** с понятной подписью темы словами, без номеров: «Подробнее: аллергия», «Подробнее: сон»; если разделов два-три — две-три серые кнопки.
5. **Номера тем и разделов на кнопках не показывать** — они остаются в адресе ссылки и в печатной версии.
6. **Телефон:** кнопки во всю ширину, высота не меньше 44 px; красный цвет — только для срочного, чтобы его нельзя было спутать с остальным.
7. **Возврат** — по правилам выше: кнопка «Назад к навигатору» возвращает к той же карточке.

**Что подготовить в тексте:** для каждой ссылки «Где читать» — короткая подпись кнопки словами (2–3 слова). Сделать при вёрстке HTML; в `draft.md` (основа печатной версии) остаются номера тем и разделов.
