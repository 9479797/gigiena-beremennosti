# HTML-версия книги: навигация

Решения пользователя для онлайн-версии книги: навигация и интерактивные элементы. Применять при вёрстке в HTML.

## 18.10.2026 — навигаторы и обратные ссылки

1. **Навигаторы (Приложение 1 — обе части, таблица Раздела 0).** В HTML вместо таблицы — список строк «Что вы заметили» (или «Что случилось или предстоит»). Под каждой строкой — ссылки, которые открывают нужные материалы: раздел темы и, если нужно, пункт Раздела 0. Текст и оформление ссылок продумать отдельно (варианты: «Открыть: Тема 11, раздел 11.2», «Читать подробнее», кнопка с названием раздела; ссылка на Раздел 0 выделяется как срочная).
2. **Обратная ссылка из материала.** В разделе, куда перешла читательница, есть ссылка «назад», и она возвращает **ровно в то место, где была нажата ссылка «открыть»**: к той же строке навигатора, а не в начало приложения.
3. **Навигация по пути читательницы.** Возврат определяется тем, откуда она пришла (из Приложения 1, Раздела 0, Введения или другой темы), а не фиксированной ссылкой. Если пришла не по ссылке (напрямую, из поиска), ссылка «назад» не показывается или ведёт к оглавлению — решить при разработке.
4. Те же правила — для всех перекрёстных ссылок вида «Подробнее: Тема N, раздел N.N».

## Что подготовить в текстах

- У каждого раздела и пункта Раздела 0 — постоянный якорь (например, `#t11-2`, `#r0-9`), чтобы ссылки не ломались при правках текста.
- У каждой строки навигаторов — свой якорь (например, `#p1-sheveleniya`), чтобы было куда возвращаться.

## 20.10.2026 — интерактивные элементы приложений (пункты 1–2 — решения пользователя)

1. **Приложение 2 «Мои лекарства и добавки» — скачать пустую таблицу.** Рядом с таблицей кнопка «Скачать таблицу для печати»: файл с пустой таблицей теми же столбцами (PDF для печати; по возможности ещё редактируемый файл — решить при разработке). Таблица в HTML остаётся видимой как образец.
2. **Приложение 4 — запросы для ИИ с кнопкой «Скопировать».** У каждой заготовки — поле ввода (название лекарства, продукта, симптома и т. п.) и необязательное поле срока или переключатель «беременна / планирую беременность». Кнопка «Скопировать» собирает в буфер обмена полный текст: вводная фраза + запрос с вписанным значением + блок «Требования к ответу». Пустое поле — кнопка неактивна или подсказка «впишите название». Введённое никуда не отправляется и не сохраняется: всё делается в браузере. Под кнопкой — подсказка «Вставьте в окно чат-бота». Тексты заготовок и разбор вопросов — `themes/appendices/voprosy-v-internete-i-prompty.md`.
3. *Предложение, пользователем не утверждено.* **Приложение 5 — чек-лист с отметками.** Пункты чек-листа — флажки, которые можно отметить на экране; ссылки на российские ресурсы проверки лекарств открываются в новой вкладке.
