# HTML-версия книги: навигация

Решения пользователя для онлайн-версии книги. Применять при вёрстке в HTML.

## 18.10.2026 — навигаторы и обратные ссылки

1. **Навигаторы (Приложение 1 — обе части, таблица Раздела 0).** В HTML вместо таблицы — список строк «Что вы заметили» (или «Что случилось или предстоит»). Под каждой строкой — ссылки, которые открывают нужные материалы: раздел темы и, если нужно, пункт Раздела 0. Текст и оформление ссылок продумать отдельно (варианты: «Открыть: Тема 11, раздел 11.2», «Читать подробнее», кнопка с названием раздела; ссылка на Раздел 0 выделяется как срочная).
2. **Обратная ссылка из материала.** В разделе, куда перешла читательница, есть ссылка «назад», и она возвращает **ровно в то место, где была нажата ссылка «открыть»**: к той же строке навигатора, а не в начало приложения.
3. **Навигация по пути читательницы.** Возврат определяется тем, откуда она пришла (из Приложения 1, Раздела 0, Введения или другой темы), а не фиксированной ссылкой. Если пришла не по ссылке (напрямую, из поиска), ссылка «назад» не показывается или ведёт к оглавлению — решить при разработке.
4. Те же правила — для всех перекрёстных ссылок вида «Подробнее: Тема N, раздел N.N».

## Что подготовить в текстах

- У каждого раздела и пункта Раздела 0 — постоянный якорь (например, `#t11-2`, `#r0-9`), чтобы ссылки не ломались при правках текста.
- У каждой строки навигаторов — свой якорь (например, `#p1-sheveleniya`), чтобы было куда возвращаться.
