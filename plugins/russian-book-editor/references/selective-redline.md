# Выборочный редлайн нерешённых мест

Использовать только для `AMBIGUOUS_MEANING` и `CONTENT_OR_MEDICAL_GAP`.

## Принцип

Редлайн показывает не историю всей редактуры, а только те места, где редактор не
может безопасно установить авторский смысл. Обычные исправления не включать.

## Формат одного фрагмента

```markdown
### UR-01 — AMBIGUOUS_MEANING

**Контекст:** одно-два соседних предложения, необходимые для решения.

**Исходный фрагмент:** «Полная исходная фраза с **выделенной неясной частью**».

**Почему нельзя исправить однозначно:** точное описание логического разрыва.

**Толкование A:** первый содержательно возможный смысл.

**Толкование B:** второй содержательно возможный смысл.

**Что нужно уточнить:** один конкретный вопрос пользователю.

**Риск догадки:** что изменится в понимании, действии или медицинском смысле.
```

Для `CONTENT_OR_MEDICAL_GAP` вместо толкований указать:

- какой факт, критерий, адресат или медицинское решение отсутствует;
- к какому этапу нужно вернуться;
- почему стилистическая правка не решает проблему.

## Общий статус

После всех записей вывести один статус:

- `STATUS: AWAITING USER DECISION` — нужен выбор авторского смысла;
- `STATUS: RETURN TO CONTENT/MEDICAL REVIEW` — нужен факт или медицинское
  решение.

Не публиковать после такого статуса чистый «финальный» текст.

## После ответа пользователя

1. Зафиксировать выбранное толкование как решение.
2. Отредактировать фрагмент и при необходимости соседние предложения.
3. Повторить Logic Map и Reader Misinterpretation Test.
4. Проверить Semantic Regression и, при заданном образце, авторский голос.
5. Убедиться, что других нерешённых мест не осталось.
6. Выдать полный чистый текст со статусом `CLEAN READY`.

## Что не считать нерешённостью

- выбор между двумя равноточными естественными формулировками;
- вопрос вкуса, ритма или предпочтительного слова;
- калька, канцелярит или порядок слов при однозначном смысле;
- необходимость сохранить профессиональный термин;
- исправленная пунктуация или типографика.
