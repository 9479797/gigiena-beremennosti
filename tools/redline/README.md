# Инструменты редлайна (этап «Сверка авторской редакции»)

Запуск: `python3 -I <скрипт> …`. Индексы абзацев — номера в `docx.Document(...).paragraphs`, включая пустые абзацы.

| Скрипт | Что делает |
|---|---|
| `redline.py SRC OPS.py OUT` | Правка абзацев по словарю `E = {индекс: новый_текст}`: разница по словам, удалённое — красным зачёркнутым, новое — фиолетовым. Пустая строка — абзац зачёркивается целиком. |
| `build_section.py OPS.py SRC OUT` | После `redline.py`: вставка новых абзацев и границ блоков `INS = {индекс: [(текст, вид)]}` (вид: `body`, `list` — как абзац-якорь, `acc` — граница блока, жирным), смена номера заголовка `HEAD = (индекс, 'старый', 'новый')`, перенос `MOVE = (с, по, перед)`, заметки `NOTES` в начало, обрезка файла до раздела `CROP = (первый абзац раздела, первый абзац следующего)`. |
| `merge_ops.py OUT.py ops1.py ops2.py …` | Собирает ops-файлы разделов в один: `E`, `INS`, причины правок каждого раздела (`NOTES[1:]`) перед его заголовком. `HEAD`, `MOVE`, `NOTES` дописать в OUT.py вручную. |
| `build_all.py OPS.py SRC OUT` | После `redline.py` на собранном ops-файле: единый файл всей темы с заметками перед разделами. |

Порядок для раздела: ops-файл раздела → `redline.py` → `build_section.py` (с `CROP`). Для всей темы: `merge_ops.py` → дописать `HEAD/MOVE/NOTES` → `redline.py` → `build_all.py`.

Удобно составлять ops-файл через словарь текстов абзацев и замену фрагмента: `rep(i, 'было', 'стало')` — тогда изменяется только нужное место, остальной абзац остаётся текстом автора.
