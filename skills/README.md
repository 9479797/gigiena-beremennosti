# Skills проекта

В этой папке хранятся одиночные Markdown-skills проекта «Гигиена беременности», которые не оформлены как полноценные plugin-пакеты.

Каждый такой skill хранится как отдельный файл `.md`.

## Текущие skills

- `methodical-review.md` — независимая методическая экспертиза после Checkpoint 4 и перед Checkpoint 5. Проверяет аудиторию, педагогическую логику, применимость, cognitive load, actionability и риск неверного толкования; не переписывает текст и не заменяет медицинскую проверку.

Полноценные пакеты с `SKILL.md`, `agents/`, `references/`, `assets/` и другими внутренними файлами хранятся в `plugins/`.
