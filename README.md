# Гигиена беременности

Репозиторий проекта книги «Гигиена беременности».

Здесь хранятся тексты тем книги, исследовательские материалы, источники, редакционные инструкции и skills, используемые при подготовке и проверке материалов.

## Структура репозитория

- `themes/` — тексты тем книги. Темы добавляются по мере их разработки и корректировки.
- `research/` — research briefs, source audits, coverage audits и другие исследовательские материалы.
- `skills/` — редакторские, методологические и проверочные skills проекта.
- `editorial/` — редакционный workflow, Checkpoint'ы, критерии качества и инструкции проекта.
- `sources/` — клинические рекомендации, руководства, научные публикации и другие источники.

## Принцип работы

Материалы проходят последовательную разработку и проверку перед включением в итоговую версию книги.

Основные уровни проработки материала:

`MENTIONED` → `PRESENT` → `EXPLAINED` → `ACTIONABLE` → `COMPLETE`

Финальные темы должны быть понятны читателю без специальной медицинской подготовки, практически полезны и опираться на проверяемые медицинские источники.

## Работа с версиями

История изменений хранится средствами Git и GitHub.

Старые копии файлов не создаются без необходимости. Значимые изменения фиксируются отдельными commit'ами с понятным описанием.

## Статус проекта

Проект находится в активной разработке.
