# Темы книги

В этой папке хранятся исходные, рабочие и финальные тексты тем книги «Гигиена беременности».

## Принцип размещения

Папки отдельных тем создаются постепенно, по мере фактической разработки и утверждения темы. Не создавать заранее пустые каталоги для всех будущих тем.

- `theme-1/` — Theme 1; прошла совместную редактуру тем 1–3, содержит незакрытые `[ПРОВЕРИТЬ]`, ждёт ответов врача-консультанта. Не эталон глубины и не STYLE CANON; опора — спецификации v1.1 (`editorial/text-architecture-v1.1.md`, `editorial/tone-of-voice-v1.1.md`), тема иллюстрирует их применение.
- `theme-2/`, `theme-3/`, `theme-4/` — прошли совместную редактуру, содержат незакрытые `[ПРОВЕРИТЬ]`, ждут ответов врача-консультанта. Не STYLE CANON.
- `theme-5/` — Theme 5; поступила извне маршрута, проходит §16, реестра утверждений нет, открыты строки 17–19 `editorial/DISPUTED-CLAIMS.md`.
- `theme-6/` — Theme 6; Checkpoint 4 пройден, hold `MIDWIFE REVIEW PENDING`, открыты строки 12–16 `editorial/DISPUTED-CLAIMS.md`.
- `theme-7/` — Theme 7; Checkpoint 4 пройден и выполнена полная редакторская сверка вне маршрута, hold перед живой экспертизой, Checkpoint 2 не завершён (26 строк реестра из 67 не в статусе `VERIFIED`).
- `темы гигиена беременности — SOURCE TEXT 2–9.docx` — общий резервуар исходных текстов. Это source text, а не approved canon и не медицинское доказательство.
- `SOURCE-TEXT-MAPPING.md` — обязательная карта маршрутизации legacy-блоков SOURCE TEXT в актуальные Theme 2–11, Section 0 и Orientation по Content Map v3.0.

Номера и названия тем внутри SOURCE TEXT являются **legacy labels**. Не использовать номер legacy-темы как номер актуальной темы книги: сначала определить активную тему по Content Map v3.0, затем свериться с `SOURCE-TEXT-MAPPING.md`.

По мере разработки очередной темы её актуальные рабочие и финальные материалы переносятся/добавляются в соответствующую папку `theme-N/`. Общий SOURCE TEXT сохраняется как исходная база и не заменяется рабочей редакцией отдельной темы.

## State record темы

При фактическом начале новой темы её папка инициализируется файлом `themes/theme-N/README.md`; пустые каталоги заранее не создаются.

README конкретной темы используется как компактная карта состояния, а не как копия текста главы. В нём фиксируются по мере необходимости:

- название и общий статус темы;
- `CURRENT CHECKPOINT` и последний утверждённый Checkpoint;
- актуальный рабочий/утверждённый файл;
- ключевые approved decisions;
- `OPEN ISSUES` / holds;
- ссылки на evidence ledger и Regression Watch, если они вынесены отдельно;
- следующий допустимый шаг.

Команды `START THEME N`, `CONTINUE THEME N`, `STATUS THEME N` и `SAVE THEME N` определены в `editorial/project-instructions-v1.8.md` и используют этот state record для устойчивого продолжения работы между чатами.
