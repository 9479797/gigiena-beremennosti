# Раздел 0 — источники по пунктам

Проверка 16.10.2026 по схеме: конкретный источник → российский документ → если российского нет, формулировка для поиска → если не найдено, пометка врачу. Номера — по списку источников в `draft.md`.

## Главное правило: скорая или роддом (0.1)

| Что | Найдено |
|---|---|
| Российская основа | Приказ Минздрава № 388н (ред. 05.05.2016), п. 11 (№ 5): поводы для вызова скорой в экстренной форме — нарушения сознания, дыхания, кровообращения; психические расстройства с опасностью для себя или других; болевой синдром; травмы, отравления; кровотечения любой этиологии; роды, угроза прерывания беременности |
| Что из этого следует | При любом признаке раздела вызов скорой правомерен. Обязательная скорая — признаки угрозы жизни (сознание, дыхание, кровообращение, обильное кровотечение, сильная боль), 160/100, признаки угрозы эклампсии с давлением, нет транспорта. В остальных случаях — роддом сразу, не за рулём |
| Чего нет в российских документах | Деления «скорая» / «самой в роддом» и меры обильного кровотечения |
| Взято из зарубежных | London Ambulance Service (№ 8): обильное — прокладка промокает меньше чем за час; Tommy’s (№ 9): сильная боль и (или) кровотечение — скорая, иначе — сразу в роддом |
| Запрос для поиска | «беременная когда вызывать скорую а когда ехать в роддом самостоятельно памятка Минздрав»; «обильное кровотечение при беременности сколько прокладок в час памятка»; «клинические рекомендации предлежание плаценты приложение В информация для пациента» |
| Врачу | Да — пометка в 0.1, DISPUTED 57 |

## Итог

- В тексте 3 пометки врачу: 0.1 (деление «скорая / роддом» и мера обильного кровотечения), 0.5 (деление при преэклампсии), 0.9 (расхождение российских документов о шевелениях).
- Российского документа не нашлось для: меры обильного кровотечения; срока обращения при тромбозе; срока «сразу» после падения; первой помощи при судорогах; первой помощи при тепловом ударе. Запросы — в таблицах выше.
