По process spec v1.8, §17, для Раздела 0 вместо основы темы — перечень состояний × уровень срочности. Критерий приёмки — полнота перечня (каждое состояние Content Map присутствует хотя бы одной строкой) и находимость.

## Действия раздела

- **скорая** — 103 или 112;
- **роддом** — приёмное отделение роддома сейчас;
- **травмпункт сегодня** — только для укусов (0.14).

Уровни «обсудить на приёме» и «связаться раньше» в Разделе 0 не описываются — основное место Тема 11, 11.6–11.7 (решение 15.10.2026).
