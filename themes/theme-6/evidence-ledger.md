# Evidence ledger — Тема 6

Журнал ведётся **с Checkpoint 0** и обновляется на каждом этапе, где текст
меняется. Тема не может пройти prepress-аудит, если в журнале остались строки
без статуса.

Правила связи утверждения с источником, порядок сверки, иерархия источников
по функции и формат списка `SOURCE NEEDED` — в
`editorial/source-verification-v1.0.md`. Этот файл задаёт форму журнала;
правила его заполнения — там.

---

## Правила ведения

1. **Одно утверждение — одна строка.** Утверждение записывается так, как оно
   звучит в тексте, а не в обобщённом виде.
2. **Строка заводится в момент появления утверждения в черновике**, а не
   после написания темы.
3. **Утверждение без строки в журнале не остаётся в тексте.** Это относится и
   к тем фразам, которые кажутся общеизвестными.
4. **Отрицательное утверждение требует источника наравне с положительным.**
   «Эффективность не доказана» — такое же фактическое утверждение, как
   «эффективность доказана».
5. **Ссылка должна открываться.** Обёртки через поисковые системы
   (`google.com/search?q=…`) источником не считаются.
6. **Российские рекомендации проверяются первыми.** Международное
   руководство не переносится в российский контекст без отдельной отметки о
   применимости.

## Что подлежит записи

- числа, диапазоны, пороги, сроки;
- противопоказания и ограничения;
- утверждения о причинно-следственной связи;
- сравнительные утверждения («А действует сильнее, чем Б»);
- частотные утверждения («чаще всего», «у большинства»);
- красные флаги и критерии обращения к врачу;
- утверждения об отсутствии или слабости доказательств.

## Что не подлежит записи

- бытовые детали и описания ощущений без медицинского содержания;
- навигация по книге;
- стилистические и структурные решения.

## Статусы

| Статус | Значение |
|---|---|
| `VERIFIED` | Подтверждено источником нужного уровня, применимость к российскому контексту проверена |
| `QUALIFIED` | Подтверждено с оговоркой: ограниченная популяция, спорная применимость, устаревающий источник |
| `CORRECTED` | Исходное утверждение было неверным, текст исправлен |
| `EXPANDED` | Утверждение было неполным, дополнено |
| `UNRESOLVED` | Источники противоречат друг другу либо вопрос открыт в науке |
| `SOURCE NEEDED` | Источник не найден; утверждение не может остаться в тексте в текущем виде |
| `REVIEWER VERIFIED` | Подтверждено медицинским рецензентом |
| `REVIEWER CORRECTED` | Исправлено по замечанию рецензента; формулировку правит автор |
| `REVIEWER REJECTED` | Отклонено рецензентом, снято из текста; узел перестраивается без него |

`SOURCE NEEDED` и `UNRESOLVED` — блокирующие статусы для prepress-аудита.
`UNRESOLVED` допустим в тексте только при условии, что неопределённость
проговорена читательнице прямо.

Статусы `REVIEWER VERIFIED` / `REVIEWER CORRECTED` / `REVIEWER REJECTED`
проставляет медицинский рецензент по `editorial/human-review-roles-v1.0.md`;
их значение и порядок применения — в `editorial/source-verification-v1.0.md`,
раздел 6.
