# Mapping исходного SOURCE TEXT на активную архитектуру v3.0

Этот файл служит только для маршрутизации материалов из `темы гигиена беременности — SOURCE TEXT 2–9.docx` в действующую архитектуру книги.

**SOURCE TEXT — это резервуар исходного материала, а не approved canon и не медицинское доказательство.** Номера и названия тем внутри исходного DOCX являются legacy labels. Они не определяют номер или границы темы в текущей книге.

Архитектуру всегда определяет `editorial/pregnancy-book-evidence-content-map-v3.0.md`. При извлечении материала сначала выбрать активную тему по Content Map, затем использовать эту таблицу для поиска подходящих исходных блоков по содержанию.

## Правила маршрутизации

1. Не выбирать исходный материал только по совпадению номера темы.
2. Не переносить legacy-заголовок, границы или порядок разделов как утверждённую архитектуру.
3. Один legacy-блок может быть разделён между несколькими активными разделами, если это требует Content Map.
4. Материал, которого нет в SOURCE TEXT, не считать отсутствующим из книги автоматически: проверить coverage активной темы и провести необходимый research/evidence pass.
5. Медицинские утверждения SOURCE TEXT всегда требуют проверки на соответствующем медицинском этапе; наличие текста не является evidence.
6. По мере создания отдельных рабочих файлов темы этот общий SOURCE TEXT сохранять как исходный резервуар и не заменять им approved canon темы.
