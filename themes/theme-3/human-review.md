# Human review — Тема 3

Фиксирует результаты трёх живых участников маршрута v1.7: акушерки-редактора, врача-рецензента/консультанта, пользователя-читателя. Prepress-аудит проверяет наличие этого файла и статус каждой секции.

Правила ведения:

1. Ответ участника вносится **дословно**, без пересказа.
2. Статус секции: `PENDING` — отправлено, ответа нет; `RECEIVED` — ответ получен, ещё не встроен; `INTEGRATED` — правки встроены автором, зависимые проверки повторены.
3. Открытые вопросы к врачу-консультанту по всем темам ведутся в `editorial/DISPUTED-CLAIMS.md`; здесь — только дословные ответы и что с ними сделано.
