# Human review — Тема 2

Фиксирует результаты трёх живых участников маршрута v1.7: акушерки-редактора (между Checkpoint 4 и Checkpoint 5), врача-рецензента (после Checkpoint 5), пользователя-читателя (после Depth review №2). Prepress-аудит проверяет наличие этого файла и статус каждой секции, а не верит на слово: положительный вердикт невозможен, пока секции 1 и 2 не в статусе `INTEGRATED`, а секция 3 не закрыта.

Правила ведения:

1. Ответ участника вносится **дословно**, без пересказа.
2. Статус секции: `PENDING` — отправлено, ответа нет; `RECEIVED` — ответ получен, ещё не встроен; `INTEGRATED` — правки встроены автором, зависимые проверки повторены.
3. Статусы `REVIEWER VERIFIED` / `REVIEWER CORRECTED` / `REVIEWER REJECTED` в `evidence-ledger.md` вносит автор дословно по ответу врача из секции 2; оригинал ответа хранится здесь.
4. Читательская проверка (секция 3) закрыта, когда пользователь вернул список мест или явно сказал, что замечаний нет.

**Общий принцип от рецензента:** помечать для неё места, где текст «перегибает» — то, что нельзя обосновать, чего нет в практике РФ, либо патология настолько редкая, что не имеет смысла в книге для широкой аудитории.
