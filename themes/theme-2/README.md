5. **Доказательная база правила о позе сна** — узел 3 (разд. 2.4). Cronin R.S. et al., EClinicalMedicine, 2019 (индивидуальный метаанализ участниц, PMC6543252): скорректированное отношение шансов для положения на спине при засыпании — 2,63 (95% ДИ 1,72–4,04); для правого бока — 1,04 (эквивалент левого); включались беременности от 28 недель. Методическая заметка: в литературе есть и более высокие оценки (отдельное новозеландское исследование — около 3,7), для книги выбрано консервативное значение из IPD-метаанализа. Действующая глава называет «28 полных недель» и «любой бок», но **без цифр и без ссылок**. (`evidence-ledger.md`, строки 5, 7.)
6. **Пробуждение на спине среди ночи** — узел 3 (разд. 2.4). Прямых данных о риске кратковременного пробуждения на спине **нет**: Cronin оценивал позу при засыпании, а не смену позы ночью. Успокаивающая фраза «это не повод для тревоги» опирается на отсутствие данных, а не на исследование (`UNRESOLVED`). Действующая глава даёт эту фразу без оговорки. (`evidence-ledger.md`, строка 6.)
